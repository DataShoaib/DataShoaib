## 🏆 3 Projects That Prove It

### ⚙️ 1. Health Insurance MLOps Pipeline
> *"Most freshers train a model and stop. I built what comes after."*

| Stage | Tool | What it does |
|-------|------|-------------|
| Data versioning | DVC + AWS S3 | Every dataset version tracked, fully reproducible |
| Experiment tracking | MLflow | All runs logged — params, metrics, artifacts |
| Inference API | FastAPI | Production REST API with input validation |
| Containerisation | Docker | Packaged for consistent deployment anywhere |

| Monitoring | Prometheus + Grafana | Live latency, error rate, and drift alerts |

**Stack:** `Python` `FastAPI` `Docker` `MLflow` `DVC` `AWS EC2` `AWS ECR` `AWS S3` `GitHub Actions` `Prometheus` `Grafana`

### 🤖 2. HR Policy RAG System — 9-Strategy Benchmarking
> *"Not a chatbot. A reproducible evaluation framework."*

Most RAG projects copy a tutorial. I benchmarked **9 retrieval strategies** and measured each one with real metrics.

| What I tested | How I measured |
|---------------|---------------|
| Naive RAG · BM25 · Dense · Hybrid BM25+Dense | Context Precision (RAGAS) |
| HyDE · Parent-Child · Cross-Encoder Reranking · MMR | Faithfulness (RAGAS) |
| Contextual Compression | Answer Relevancy (RAGAS) |

All 9 experiments tracked in **MLflow + LangSmith** — fully reproducible, not a one-time demo.

**Stack:** `LangChain v0.3` `ChromaDB` `Groq API` `Llama 3.1 8B` `RAGAS` `MLflow` `LangSmith`
